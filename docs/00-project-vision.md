# Project Vision

This repository is a practical showcase for modern QA automation supported by AI agents.

It should demonstrate how a team can move from requirement analysis to automated tests, code review, CI execution, and reporting while keeping the process transparent and repeatable.

## Goals

- Keep the demo small enough to understand quickly.
- Show production-like testing patterns without unnecessary enterprise weight.
- Compare Selenium Python and Playwright TypeScript on the same business flows.
- Run the tested application in Docker for stable local and CI execution.
- Document AI-agent collaboration as reusable prompts and workflow examples.

## Non-goals

- Building a full production e-commerce application.
- Replacing human test design with unreviewed AI output.
- Depending on external websites for critical CI checks.
